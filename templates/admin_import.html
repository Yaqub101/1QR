The university's list, as a CSV or an Excel file. You will see exactly what will happen before anything is written, and you can run the same file again later when the rest of the list arrives: students already on the list are left exactly as they are.

The university's photo ZIP (for example Student Profile Image.zip). Each photo is matched to its student by the PRN or Enrollment / Roll number in its file name. Photos are added after the students, and students already on the list keep the photo they have.

What happens next

  1. Match the columns. Recognised headings are matched for you; anything unusual you set yourself.
  2. Read the check. Missing fields, repeated PRNs, overlong names, missing photos, rows marked inactive and students already on the list — all before anything is written.
  3. Import. The whole file goes in together, or none of it does.
