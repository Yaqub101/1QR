Import Workflow Stages

  1. 1. Column Alignment: Standard headings are auto-mapped; custom or localized headings can be mapped manually.
  2. 2. Verification & Dry-Run: Missing fields, repeated PRNs, overlong names, and duplicate entries are flagged without touching database state.
  3. 3. Atomic Commit: The entire cohort is committed in a single transaction, or fully rolled back if validation fails.
